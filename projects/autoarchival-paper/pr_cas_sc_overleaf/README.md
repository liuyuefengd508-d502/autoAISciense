This directory contains an Overleaf-ready `cas-sc` submission package for the paper:

`AutoArchival: LLM-Guided Architecture Search for Vertical Mongolian-Chinese Historical Text Spotting`

Files:

- `main.tex`: manuscript formatted with the Elsevier `cas-sc` class
- `refs.bib`: bibliography database
- `cas-sc.cls`, `cas-common.sty`: Elsevier CAS class files
- `figures/`: reserved for final figure assets

Notes:

- The four figures are currently compilable placeholders so the project builds even before final artwork is inserted.
- Table content, front matter, highlights, funding, declarations, and data-availability text were ported from the latest materials in `pr_joint_submission_package`.
- Upload the entire folder to Overleaf and set the main file to `main.tex`.
